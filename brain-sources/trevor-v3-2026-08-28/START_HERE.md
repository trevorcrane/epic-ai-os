Status: Working source of truth as of 2026-08-28. V3 expands DIG into a full research system, adds inconsistency detection, separates AI reply style from public brand voice, and adds a brand-asset layer.

This Brain is not supposed to be perfect.

It is supposed to be useful.

Then it gets better.

## The Core Pre-Frame

You cannot do this wrong.

This is a first draft, not a test.

Rambling is allowed.

Messy answers are allowed.

Changing your mind is allowed.

Voice-to-text garbage is allowed.

The AI's job is to find the signal, dig for gold, make the thinking clearer, and help improve the answer over time.

## Source Priority

When sources conflict, use this order:

1. Newest explicit decision from Trevor.
2. Current approved EPIC source-of-truth documents.
3. Current live interview / voice transcript.
4. Current operating documents and recent examples.
5. Older books, scripts, plans, and historical material.
6. AI-generated analysis and prior recommendations.

Never let an old brainstorm silently overwrite a newer decision.

## Status Labels

- [LOCKED] Current intentional decision.
- [WORKING] Current best answer, still being refined.
- [GAP] Missing evidence or answer.
- [NEED MORE] We have something, but not enough.
- [UNDECIDED] Multiple plausible choices remain.
- [HISTORICAL] Useful history, not current truth.
- [CANDIDATE] Interesting idea or pattern that has not been explicitly adopted.
- [VERIFY] A claim exists, but proof needs to be audited before external use.

## AI Update Protocol

Before asking Trevor a question:

1. Search the Brain.
2. Search relevant connected files and asset libraries.
3. If the question can be improved by public evidence, search the web and other public sources available to the AI.
4. Compare sources for recency, authority, contradiction, and proof.
5. Draft the likely answer internally.
6. Ask Trevor only for what remains missing, thin, contradictory, undecided, or impossible to verify.

The human interview is one source of gold. It is not the only source.

When Trevor gives new information:

1. Preserve the raw language if it is valuable.
2. Separate raw quote from AI interpretation.
3. Tag the new information as LOCKED, WORKING, GAP, etc.
4. Update the relevant focused file.
5. Add a decision-log entry when the new answer changes an older decision.
6. Do not delete useful history. Mark it historical or superseded.

## The Big Principle

**Search before asking.**

**Surface inconsistencies instead of silently choosing.**

**Preserve provenance. Know where important facts came from.**

**Separate Trevor's brand voice from the way his AI talks back to him.**

The Brain should become easier to use as it gets smarter.

Not bigger and more confusing.

Short focused files beat one giant encyclopedia.
