## Proof Standard

State the facts.

Tell the truth.

Never make proof prettier than it is.

For every claim, distinguish:

- CLAIMED
- DOCUMENTED
- VERIFIED
- AUDITED
- APPROVED FOR PUBLIC USE

Those are not the same thing.
