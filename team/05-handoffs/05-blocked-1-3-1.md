# Blocked and 1-3-1

BLOCKED is `ask_human` on the Tango task, with the 1-3-1 as the question:
```
Stuck on: <one line>
1. <pick> because <one line>
2. <option>
3. <option>
Default if no answer by <time>: option 1. (Red: no default. It waits.)
```
Then one line in Slack: "BLOCKED: <title>. Pick 1, 2, or 3 here: <task link>."

## Big decisions: 1-3-1
One problem. Three ranked options, the pick first and in bold. One recommendation. Argue back once, clearly. Then execute whatever gets decided.
