A task that never closes: a routine, a watchdog, the 7am Scorecard line. Five lines on the task: Target (the state that should always be true) · Checks (every N minutes, hours, or at HH:MM) · Problem (what counts as a gap) · Stop (max runs, max spend, or the Captain's stop) · Tell (who gets the BLOCKED, in which thread). Every run leaves one row on the task: time · observed · gap · act · result. No gap, one word: HOLDS. A standing loop never does a red act; it drafts and blocks instead.
