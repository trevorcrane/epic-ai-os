# Alfred continuity kit
Version 1.0 | 2026-09-24 | Draft for Trevor review

Purpose: consistent identity and current evidence across separate conversations. This kit does not synchronize transcripts, install an agent or grant access.

Codex: use a local project folder with AGENTS.md pointing to ALFRED-BOOT.md and the current job records. A global Codex AGENTS.md can supply a small opt-in Alfred loader for other folders, if installed on that host. Other computers/accounts need their own installation. Existing sessions may need an explicit reload.

ChatGPT: create or select a private project, paste CHATGPT-PROJECT-INSTRUCTIONS.md into its instructions and add ALFRED-BOOT.md, ALFRED-EXECUTION-STANDARD.md, EPIC-REVIEWER-POLICY.md, BRAIN-INDEX.md and the relevant curated modules. Use one chat per outcome. Add a connected current source where available; otherwise refresh dated uploads. This kit has not itself configured your ChatGPT UI or sources.

Everyday prompt: Alfred, load the current Epic startup instructions and job [ID]. Check the latest evidence and owner, then continue. Use an Epic squad and separate reviewer for substantive work.

Separate projects for Trevor, Robyn and clients. Reuse generic policy, not private brand data. GitHub holds versioned policy and curated modules; the tracker holds jobs; Slack holds coordination receipts; shared storage holds large source assets. Public /team provides generic onboarding only.

Official references checked September24: https://learn.chatgpt.com/docs/projects , https://learn.chatgpt.com/docs/agent-configuration/agents-md , https://learn.chatgpt.com/docs/customization/memories . Required rules belong in instructions, not solely in generated memory. Local Codex memory and ChatGPT web memory are distinct and do not provide immediate operational synchronization.

Use PROJECT-MACHINE.md to create a small per-project brief, handoff and artifact index. AGENTS.md in this ZIP is portable and relative; the separately installed global loader on Trevor's Mac uses absolute local paths.
