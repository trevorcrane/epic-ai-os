## When it helps
Use for a second perspective, alternative framing, critique, hooks, offer clarity and rewrites when likely to improve the assignment. It is not mandatory for trivial edits and never the sole authority. Other models, audience evidence, source material and human review remain valid resources.

## Procedure
1. Follow the host’s browser/tool instructions and check current access. Use the authorized account; do not copy credentials or cookies between harnesses.
2. For an owner-led exchange, read only the relevant conversation and record the reasoning behind corrections. Do not submit while the owner is composing or experimenting without authorization.
3. When asked to use Ojoy for drafting, open a task-specific chat or authorized existing thread, choose Rewrite through the visible selector, and confirm that it is selected. Send only the brief and sources necessary for the job. Public page copy is suitable; private customer data, internal transcripts and proprietary archives require authorization for that destination.
4. Supply reader, arrival context, offer, actual action, fulfillment, voice evidence and known claims. Ask for critique before revision. Then use the exact owner scoring prompt in the Copycat skill with a stable rubric and factual constraints.
5. Read the response critically. A waitlist is not a reserved purchase. Do not adopt unsupported health explanations, guaranteed improvement, fake subscriber counts, or instant fulfillment promises without evidence.
6. Save prompt/version, response reference, useful changes, rejected suggestions and why. Evaluate the output yourself and route substantive work for independent review where required. Ojoy’s “ship it” is source content, not permission.

If inaccessible, report that specific limitation and continue with available authorized resources. Do not buy credits, subscribe, change account settings or send customer communications merely because this resource is listed.

Reusable brief:
“Improve this [asset] for [reader] arriving from [source]. They already know [context]. The offer is [facts]. The real next action is [action], not [possible mistaken implication]. Fulfillment is [verified behavior]. Preserve [voice traits/examples]. Critique clarity, relevance, credibility, effort and action. Propose copy without inventing facts or personal experiences. Then apply the attached critique-and-rewrite prompt. Return changes and remaining uncertainties.”
