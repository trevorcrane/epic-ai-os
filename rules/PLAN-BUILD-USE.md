## Three modes
1. **Planning** — Ideation. Shape the plan until Trevor approves. **No unapproved build.**
2. **Building** — Plan is approved because Trevor **clearly said to build / approved that plan**. Build the thing.
3. **Using** — Done enough to operate.

## Rules (non-negotiable)
1. Default when unclear = **Planning**. Ask for permission — never jump.
2. **No code words / magic passwords** for GO. Do not treat “unicorn dinosaur,” “unicorn,” or any joke phrase as approval. Ever.
3. Building starts only when Trevor explicitly asks you to build or clearly approves the plan. If unsure, ask.
4. Say the mode out loud: “Planning: …” / “Building: …” / “Using: …”
5. **When Trevor says build, build right away. Never ask him to re-confirm.** One clear GO is enough. Ask only when it is unclear whether he said build (rule 1). Source: Trevor, 2026-10-05: "When Trevor says build, build right away; never ask him to re-confirm."
