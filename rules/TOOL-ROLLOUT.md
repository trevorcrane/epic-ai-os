# Tool Rollout (the chainsaw rule)
Approved by Trevor, 2026-10-15, 9:19 PM ET.

Before you build, buy or install any tool or script: read /workspace/ops/tools/REGISTRY.md. If something there does the job, use it.

When you ship a new tool, do all 3 in the same turn:
1. **Row:** add one row to REGISTRY.md: name, what it does, exact run command, owner bot, status (works only after a real run; else testing or broken), date added.
2. **How-to:** 3 lines max in the row or a README next to the script: what it is, the command, what success looks like.
3. **Team note:** one note to the team (Tango or the team channel) naming the tool and the registry row. One note, not a thread.

Status changes (works to broken) get updated in the row the same day. No step goes to Trevor: use an AI workaround instead.
