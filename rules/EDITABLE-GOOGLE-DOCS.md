# Deliverables = anyone-can-edit Google Docs (FLEET LAW)

Locked 2026-09-30 from Trevor (after Hermes friction).

## Rule
When an agent hands Trevor links, resources, workflows, advice packs, lists, or research:
1. Put it in a **Google Doc** (or Sheet) that is **editable by anyone with the link** — default share: *Anyone with the link → Editor*.
2. Never give view-only unless Trevor explicitly asks for view-only.
3. Never make him log into someone else’s Chrome / account to read it.
4. **Never hand a file** (docx, pdf, zip, md attachment as the deliverable) unless he asks for a file.
5. Prefer a live editable Doc over chat walls of text for anything he’ll reuse.

## Why
He needs to open links instantly, edit, share with team — no permission theater.

## Exception
Passwords, secrets, or legal docs that must stay restricted — then ask before sharing.
