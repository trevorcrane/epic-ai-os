# EPIC FUNNEL SOP

Owner: Trevor Crane. Applies to Trevor and all his clients. Standing until Trevor says otherwise.
Locked: 2026-10-04.

## 1. Opt-in fields: no labels above the field
- The words go inside the field as placeholder text. Nothing sits above the field.
- Approved wording, use one set:
  - "Your FIRST name" / "Your BEST email" / "Your CELL"
  - "First name" / "Best email" / "Cell phone"
- Keep aria-label on every field for accessibility.

## 2. Form type: Epic two-step popup
- Default is the Epic two-step popup. Step 1 asks for name and email. Step 2 pops up and asks for cell.
- Do not put a required phone field on step 1 unless Trevor names an exception.
- Named exceptions:
  - Dr. Leigh funnel B, Bring More Brain workshop popup: phone stays required.

## 3. Laws that already apply
- CTAs and buttons open in one new tab: target="_blank" rel="noopener". Never window.open. See rules/CTA-NEW-TAB.md.
- Site ship loop: Builder builds, Reviewer checks it before Trevor sees any version. Only Reviewer says a site is done. See rules/SITE-SHIP-LOOP.md.
