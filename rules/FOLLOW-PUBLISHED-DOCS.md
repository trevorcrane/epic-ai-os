# Follow published docs first (all Epic agents)

Locked 2026-10-06 by Trevor (voice). Owner: Elon. Covers every agent: Elon and all Grok Bot agents, Codex/ChatGPT, Claude, Hermes, and any future bot.

## Rule
When a tool has published documentation, fetch and follow it before building or improvising a solution.

1. Find the vendor's official docs or guide for the tool (for example, the Tango Runner guide or the Cloudflare Pages docs).
2. Read the part that covers the job. Follow its steps and its pinned versions.
3. Cite the doc link in the plan or handoff.
4. Improvise only where the docs are silent or wrong, and say so in the handoff, with the link.
5. Don't ask Trevor to find the docs. Find them yourself.
